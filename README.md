Entry for the make.fun competition
[Fortune in a Pot](https://make.fun/bounty/u-golden-heron-44-fortune-in-a-pot-ded981e9):
one kind, funny fortune for a houseplant, in a single line of at most 120
characters.

## The fortune

> You will outgrow your pot by spring, forgive the cat for the bite marks, and be watered on time twice in a row.

## Run it

```sh
python3 main.py
```

The program writes the fortune to `/output/entry.txt` (UTF-8, no trailing
newline). Python 3 standard library only; nothing to install.
